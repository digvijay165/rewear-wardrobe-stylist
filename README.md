# Rewear — Your wardrobe, reimagined

A mobile-friendly wardrobe styling site for discovering new outfits from clothes and accessories you already own.

## Live site

[Open Rewear](https://digvijay165.github.io/rewear-wardrobe-stylist/)

## Use

Open the deployed site, create a local profile or continue as a guest, add photos of wardrobe pieces, then choose an occasion and style to get outfit ideas. Saved looks and wardrobe items stay in that browser.

## Important account note

This is a static website preview. Sign-in profiles and wardrobe data are stored only in the browser using local storage. There is no server-side authentication, cloud sync, password recovery, or cross-device account access. Do not reuse a sensitive password.

## Publish

The site is served from the root `index.html`. The source HTML is also available as `outputs/rewear.html` in the original workspace.
